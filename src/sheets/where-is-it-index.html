Where Is It? — House Index

"Mom, where are the batteries?" is a daily question with no owner. Give every common item one answer, written down, taped where all can see it.

  1. Do NOT start from scratch: walk your kitchen and utility room once and write what you remember most.
  2. Keep the page on the fridge or inside a cabinet door everyone opens anyway.
  3. Each time somebody asks "where is it?", after you answer, add a row. The index grows itself.

Tip: always write locations the same way — "kitchen drawer 3" not "the good drawer." Future-you reads them literally.
