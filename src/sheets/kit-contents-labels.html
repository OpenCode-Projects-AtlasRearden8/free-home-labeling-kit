Kit Contents Labels

A kit only helps if you know what is inside it before you need it. Tape this list to the lid — first aid, sewing, and school kits, three ordinary lifelines.

  1. Open each kit and check off what is really in there, adding what belongs and is missing.
  2. Add today's date on the "Checked" line so future-you trusts the list.
  3. Tape it inside the lid, or slip it in a clear pocket on front.

Tip: check each kit once a year — the start of a school year is an easy date to remember.
